Arr Connections

Multiple Radarr / Sonarr instances supported
Successful Test saves only that connection. Blank API key keeps the currently saved key.
Automatic grabs: with Watch Radarr/Sonarr on (Performance section), the API connection is enough. The webhook is optional and instant: add its URL in Radarr/Sonarr under Settings → Connect → Webhook (POST). Radarr: On File Import + On File Upgrade. Sonarr: On Import + On Series Add. On a shared Docker network you can use http://trailarr-parrk:8080 as the host. Running both is fine — the second one sees the trailer and skips.
